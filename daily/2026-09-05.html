01把實驗室 GitHub 的 16 個 repo 讀成一份可導航的全景地圖完成

問題

我的題目（腫瘤克隆演化樹推論）在實驗室裡不是孤立的，但相關的程式、資料與判斷散在十幾個 repo 與各自的文件裡。一個一個讀完要好幾天，而在那之前我沒辦法回答「這件事實驗室做過沒有」。

做法

把 org 依主題切成六塊，各派一個 subagent 去讀：定相工具的兩個分支、給 agent 讀的知識庫、官網與教材、批改與日誌那條工具鏈、各人的工作流、以及那個腫瘤演化樹專案。要求每個技術宣稱都附檔名與行號；讀不到的（要編譯的東西、存取不到的磁碟）一律標成「文件自述、未驗證」。六份底稿回來之後再整合成一份可導航的 HTML 與一份同內容、可 grep 的 Markdown。

結果

產出在 論文/實驗室全景地圖/：ccu-lab-map.html（9 節、左側目錄、repo 總表可依類別篩選）、ccu-lab-map.md（同內容）、briefs/ 六份底稿共 4,236 行。

最有用的一件事：org 裡有一個名字看起來像日誌的 repo，實際是一個完整的腫瘤克隆演化樹推論專案 —— 它的文獻座標系（PhyClone、PyClone-VI、PhyloWGS）跟我這兩天在讀的 PyClone 與 LICHeE 是同一個問題域，而跟實驗室其他工具幾乎不重疊，只在 BAM 那一層相接。

其餘發現分三類：文件與程式碼不同步的數處、對外發布版本與開發分支之間的落差、兩支工具的開發分支正在做同一件事。這幾類的具體內容沒有寫進這份公開日誌 —— 地圖裡含私有 repo、伺服器路徑與未發表研究，六個 agent 全程只寫本機檔案、沒有對外發布，這裡也照同一條線處理。

解讀

以後問「實驗室有沒有做過 X」不必再重掃一次 org，先讀這份地圖。對我自己的題目最直接的影響是那個同問題域的專案：它已經把 PyClone 式的 emission 模型實作過一輪，我從論文讀到的東西可以拿去跟一份實作對照，而不是從零開始推。

還缺

幾乎沒有程式被實際編譯或執行 —— 只有三處例外跑過該 repo 自己的檢查腳本，其餘全是讀碼推論。伺服器路徑、資料量、benchmark 數字都只能確認「文件如此記載」，沒有辦法存取實際磁碟去核。地圖第 8 節把每一項未確認的都列出來了，包含其中一條「某人手上有另一人卡住那題的解」的推論本身。

02PyClone 的數字複驗全對得上，LICHeE 的原始碼卻對不上論文兩處完成

問題

筆記已經寫到第四版，但裡面的數字與方法敘述都還沒有被獨立核過一次。要拿它去撐自己的論述之前，得先知道哪幾句站得住、哪幾句照抄會出事。

做法

PyClone 那邊：把 PDF 全文重讀一遍，逐項對回筆記，對得上就不動，對不上或筆記沒記的就回原文定位、逐字抄下來。

LICHeE 那邊：把原始碼（MIT，5,041 行 Java）抓下來，分兩個版本讀 —— 最接近論文的那次 commit（2015-02-25）與現在的 HEAD（2017-10-19），兩者 src/ 差 1,728 增 / 1,164 刪，所以凡有行為差異都分版標註。整份是靜態閱讀，沒有編譯也沒有執行。

結果

PyClone 複驗：沒有一處需要更正。 coverage、混合比例、驗證過的突變數、分群數對照、MCMC 迭代設定、V-measure 的版本，逐字元對過。

另讀出三處先前漏記的方法細節，都在 Online Methods，都是「作者做了但沒放進正文敘事」的類型：Fig. 1 的真值資料集有人工剔除離群位點、判準是目視偏離期望值、沒報告剔除幾個；那組臨床樣本的分析輸入不只公開講的那批已驗證突變；收斂診斷只做了臨床樣本那一組，模擬與混合實驗因為跑太多次而沒做。

LICHeE：兩處論文說法與實作對不上。 一是「約束網路內含所有合法樹」在預設模式下不成立 —— 建網路時只在某一層與下一個非空層之間試連邊，跨層的合法祖裔關係預設不進候選，要加旗標才會補；二是介於「有」與「沒有」之間的那批突變（greyzone）在預設參數下恆為空，因為兩個門檻預設同值，判定條件永遠為假。

三個論文完全沒提的行為。 無解時會自動刪掉一個最小的不穩定群集重搜，迴圈到有解為止（現行版本還會再自動放寬一次建邊規則）；所以回報「找到 N 棵有效樹」時，N > 0 不保證是在原始輸入與原始約束下得到的。一致性檢查在現行版本兩層都失效（參數為 0、移除邏輯被註解掉）。每位病人的參數是手調的，軟體說明檔逐案列出，論文正文沒有對應敘述。

解讀

兩篇的引用強度要分開處理。PyClone 的數字可以直接引；LICHeE 的方法敘述照論文寫會與實際跑出來的行為對不上，尤其是「窮舉所有合法樹」與「中間地帶的突變依拓撲指派」這兩句 —— 要引就得標版本，並說明是論文敘述還是實作行為。這也影響之後真的要拿它跑資料時怎麼設參數：預設值不是作者自己用的值。

還缺

沒有編譯也沒有執行過 LICHeE，所以「預設建網路排除掉多少合法拓撲」無法量化，那要實際跑才知道。LICHeE 的三份附加檔案（含與另一套方法的比較）仍未取得。PyClone 手上是作者手稿版，最終出版版的正文沒有可比對的版本，摘要已知有措辭差異。
