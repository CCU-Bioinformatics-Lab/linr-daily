摘要

今天的重心是讓每日進度管線正式上線：報告首次推上公開的進度 repo、對齊實驗室的 repo 慣例，並把工作記錄的來源延伸到實驗室伺服器。

發布面：把 2026-08-19 的報告推上進度 repo，之後比對另一位成員的 daily repo 逐項對齊設定——關閉 Wiki、報告收進 daily/ 子目錄、README 補上版面說明，發布腳本同步改路徑並以 dry run 驗證。接著驗證了 HTML 在 GitHub 上的三種開啟途徑：blob 頁只顯示原始碼是設計使然（text/plain），透過代理服務可正確渲染，正式入口則建議開 GitHub Pages。

伺服器面：設計了每日日誌回傳的流程——伺服器端的工作日誌在每天固定時間彙整、摘要當天發生的事並標註 error/warning，回傳後併入當日進度報告，隨後發布。排程已註冊，管線設定也記入持久記憶供之後的 session 接手。

其餘是知識工具與學習：把一個課程網站濃縮成單檔初學者筆記、把外部的學術閱讀工作流教材蒸餾成 literature-reading skill 納入 plugin、盤點實驗室 GitHub 的整體實驗流程並統整檢體量測流程、以互動視覺化上了一堂 EC 與 MCMC 的入門課。

過程中處理的問題：

  • PowerShell 5.1 以 -File 執行腳本時，$PSScriptRoot 在參數預設值裡是空字串導致 Split-Path 失敗；改以 & 呼叫則正常。腳本的路徑預設值不能假設呼叫方式
  • GitHub 的 raw 網址刻意以 text/plain 回應防 XSS，確認這不是設定問題，正確做法是換渲染途徑而非嘗試繞過

明天要接的：確認兩個排程（日誌彙整與報告發布）在無人值守下實際跑起來，並檢查伺服器日誌有沒有如期回傳。
